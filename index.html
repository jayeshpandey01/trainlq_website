One-Line Training.
Zero Configuration.

TrainIQ automatically detects your data types, tasks, and selects the best model architecture—whether it's tabular, image, text, or time-series data.

  • Built-in Optuna Hyperparameter Tuning
  • Rich Model Zoo (ResNet, BERT, XGBoost)
  • Export to ONNX & TorchScript instantly
train.py 
from trainiq import trainiq, trainiqConfig

# 1. Configure
config = trainiqConfig(
    data_path="data.csv",
    target_column="label",
    epochs=50
)

# 2. Train
model = trainiq(config)
results = model.train()

# 3. Export
model.export(format="onnx")

AI Research Engine

Built-in web scraper and RAG engine that uses Ollama or HuggingFace to answer complex ML architecture questions.

trainiq research "What is transfer learning?" --llm-provider huggingface
AI

Transfer learning in deep learning consists of taking features learned on one problem, and leveraging them on a new, similar problem. For instance, features from a model that has learned to identify raccoons may be useful to kick-start a model meant to identify ninjas.
