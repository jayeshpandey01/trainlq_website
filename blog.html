TrainIQ Documentation

End-to-end ML/DL pipelines with a single call. TrainIQ supports tabular, image, text, and time-series data with automatic model selection, hyperparameter tuning, and deployment.

Quick Start View on GitHub
  • Automatic Everything: Data type detection, task detection, model selection, preprocessing
  • One-Line Training: Train state-of-the-art models with a single function call
  • Hyperparameter Tuning: Built-in Optuna integration for automatic optimization
  • AI Research Assistant: Built-in WebResearch Engine with Ollama & HuggingFace LLM support
  • Easy Deployment: Export to ONNX/TorchScript + FastAPI scaffold generation

Basic Installation

pip install TrainIQ

With All Features

pip install TrainIQ[all]

It only takes a few lines of code to configure, train, and export a complete pipeline.

train.py 
from trainiq import trainiq, trainiqConfig

# 1. Initialize configuration with your dataset details
config = trainiqConfig(
    data_path="data.csv",
    target_column="label",
    epochs=50
)

# 2. Start the automated training process
# This handles data discovery, architecture selection, and optimization
model = trainiq(config)
results = model.train()

# 3. Export the "Trained Brain" for production use
model.export(format="onnx")

What's happening under the hood?

When you call model.train(), TrainIQ performs Universal Data Discovery to identify your data type, selects the optimal architecture from our Model Zoo (XGBoost, Transformers, or ResNet), and executes training with Automatic Hardware Acceleration (CUDA/MPS).

NEW IN v0.1.3

The WebResearch Engine helps you find and synthesize information from the web using AI. With built-in support for HuggingFace and local Ollama models. 

from trainiq import research

# Run a deep research query
# TrainIQ will scrape, analyze, and summarize findings
results = research(
    query="What are the latest advances in computer vision?",
    llm_provider="huggingface",
    llm_model="google/flan-t5-base",
    max_sources=5,
    research_mode="academic"
)

print(f"Synthesized Answer: {results['answer']}")

The Research Workflow

The WebResearch Engine utilizes a 3-stage process: (1) Autonomous Scraping of top citations, (2) Contextual Chunking for relevant info extraction, and (3) LLM Synthesis to generate a cited, natural-language response.

If you're new to AI, the "one-line training" might feel like magic. Let's pull back the curtain and see what happens at each step when you run a TrainIQ project.

01

The Configuration (`trainiqConfig`)

You define your data path and target. TrainIQ uses this object as a "blueprint".

What it expects:

  • data_path: Where your data is stored.
  • target_column: The name of the value you want to predict.
02

Automated Discovery

TrainIQ scans your data. If it sees a .csv, it knows it's tabular; if it's a folder of .jpg files, it switches to Image mode.

Benefit: You don't have to manually write different code for images vs. spreadsheets.

03

The Training Engine (`.train()`)

This is where the heavy lifting happens. TrainIQ builds a neural network architecture (like a "brain") and feeds it your data in small chunks (batches).

Expected Output: A history of "accuracy" scores. You'll see this number go up as the model "learns" from patterns in your data.

04

Ready for Action (`.export()`)

Finally, you save your "trained brain" so you can use it in your own apps or websites.

Output: An .onnx or .pt file.

Tabular Classification

from trainiq import trainiq, trainiqConfig

config = trainiqConfig(
    data_path="iris.csv",
    target_column="species",
    epochs=50
)

model = trainiq(config)
results = model.train()

print(f"Accuracy: {results['best_val_acc']:.4f}")

Image Classification

# Folder structure:
# images/
#   ├── cat/
#   ├── dog/
#   └── bird/

config = trainiqConfig(
    data_path="images/",
    data_type="image",
    model_name="resnet50",
    epochs=100,
    batch_size=64
)

model = trainiq(config)
results = model.train()
model.export(format="onnx")

Time-Series Forecasting

config = trainiqConfig(
    data_path="stock_prices.csv",
    data_type="timeseries",
    model_name="lstm",
    extra={
        "window": 30,    # Look back 30 time steps
        "horizon": 7     # Predict 7 steps ahead
    }
)

model = trainiq(config)
results = model.train()

Pass these arguments to trainiqConfig to fine-tune your training setup. 

config = trainiqConfig(
    # Data
    data_path="data.csv",           # Path to dataset (required)
    target_column="label",          # Target column name
    task="classification",          # "classification", "regression", "forecasting"
    data_type="tabular",            # "tabular", "image", "text", "timeseries"
    
    # Training
    epochs=50,                      # Number of epochs
    batch_size=32,                  # Batch size
    learning_rate=1e-3,             # Learning rate
    optimizer="adam",               # "adam", "adamw", "sgd"
    
    # Model
    model_name="resnet18",          # Specific model to use
    pretrained=True,                # Use pretrained weights
    
    # Hyperparameter Tuning
    tune=True,                      # Enable HPO
    tune_trials=30,                 # Number of trials
    
    # Output
    output_dir="trainiq_output",     # Output directory
    device="cuda",                  # "cpu", "cuda", "mps"
    seed=42                         # Random seed
)

Execute training, deployment, and research workflows directly from the terminal.

Basic Training

trainiq train --data data.csv --target label

Hyperparameter Tuning

trainiq train --data data.csv --target label --tune --tune-trials 50

AI Research Search

trainiq research "What is AI?" --llm-provider huggingface --llm google/flan-t5-base
