TrainIQ Documentation

End-to-end ML/DL pipelines with a single call. TrainIQ supports tabular, image, text, and time-series data with automatic model selection, hyperparameter tuning, and deployment.

Quick Start View on GitHub
  • Automatic Everything: Data type detection, task detection, model selection, preprocessing
  • One-Line Training: Train state-of-the-art models with a single function call
  • Hyperparameter Tuning: Built-in Optuna integration for automatic optimization
  • AI Research Assistant: Built-in WebResearch Engine with Ollama & HuggingFace LLM support
  • Easy Deployment: Export to ONNX/TorchScript + FastAPI scaffold generation

Basic Installation

pip install TrainIQ

With All Features

pip install TrainIQ[all]

It only takes a few lines of code to configure, train, and export a complete pipeline.

train.py 
from trainiq import trainiq, trainiqConfig

# 1. Configure
config = trainiqConfig(
    data_path="data.csv",
    target_column="label",
    epochs=50
)

# 2. Train
model = trainiq(config)
results = model.train()

# 3. Export
model.export(format="onnx")

TrainIQ is built on a modular engine that automates the decision-making process typically handled by data scientists. Understanding these core modules helps you leverage the full power of the framework.

1. Universal Data Type Detection (`detector.py`)

Most AutoML tools require you to define your data type. TrainIQ uses a majority-voting logic and file extension analysis to identify your data modality automatically.

// Detection Logic:

- Files: CSV/Excel → Tabular, JPG/PNG → Image, WAV → Audio

- Folders: Scans image structure (root/class/img) or votes based on contents.

2. Intelligent Task Inference

Once the data is loaded, TrainIQ analyzes the target column (for tabular) or the dataset structure to infer the machine learning task.

  • • Classification: Infered if target has ≤20 unique values or is an object type.
  • • Regression: Infered if target is numeric with high cardinality.
  • • Forecasting: Auto-selected for sequence/time-series data.

3. Model Zoo & Factory

TrainIQ maintains a registry of diverse architectures. It doesn't just pick one; it evaluates the best fit for your hardware and data size.

LIGHTWEIGHT

XGBoost, Random Forest, ResNet18

HEAVYWEIGHT

ResNet50, DistilBERT, Transformers

Tabular Classification

from trainiq import trainiq, trainiqConfig

config = trainiqConfig(
    data_path="iris.csv",
    target_column="species",
    epochs=50

model = trainiq(config)
results = model.train()

print(f"Accuracy: {results['best_val_acc']:.4f}")

Time-Series Forecasting

config = trainiqConfig(
    data_path="stock_prices.csv",
    data_type="timeseries",
    model_name="lstm",
    extra={
        "window": 30,    # Look back 30 time steps
        "horizon": 7     # Predict 7 steps ahead
    }
)

model = trainiq(config)
results = model.train()

Pass these arguments to trainiqConfig to fine-tune your training setup. 

config = trainiqConfig(
    # Data
    data_path="data.csv",           # Path to dataset (required)
    target_column="label",          # Target column name
    task="classification",          # "classification", "regression", "forecasting"
    data_type="tabular",            # "tabular", "image", "text", "timeseries"
    
    # Training
    epochs=50,                      # Number of epochs
    batch_size=32,                  # Batch size
    learning_rate=1e-3,             # Learning rate
    optimizer="adam",               # "adam", "adamw", "sgd"
    
    # Model
    model_name="resnet18",          # Specific model to use
    pretrained=True,                # Use pretrained weights
    
    # Hyperparameter Tuning
    tune=True,                      # Enable HPO
    tune_trials=30,                 # Number of trials
    
    # Output
    output_dir="trainiq_output",     # Output directory
    device="cuda",                  # "cpu", "cuda", "mps"
    seed=42                         # Random seed
)

Detailed breakdown of the primary functions in the trainiq package.

.train()

Orchestrates the entire training pipeline, from loading data to saving the best model.

Inputs

  • None (uses trainiqConfig)

Internal Logic

Runs detection → loads data → builds architecture → executes training loop with early stopping → saves best checkpoint.

Outputs

dict: Contains training history, best accuracy, and path to the best model.

.predict(data)

Runs inference on new, unseen data using the trained model.

Inputs

  • data: Array/Path/Image

Internal Logic

Applies the same preprocessing transformations used during training and runs a forward pass through the network.

Outputs

numpy.ndarray: The predicted labels or values.

.export(format)

Serializes the model for production environments.

Inputs

  • format: "onnx", "torchscript"

Internal Logic

Traces the model graph with dummy inputs to capture the set of operations and saves it in a hardware-agnostic format.

Outputs

str: Path to the exported model file.

CLI Usage

Execute training, deployment, and research workflows directly from the terminal.

Basic Training

trainiq train --data data.csv --target label

Hyperparameter Tuning

trainiq train --data data.csv --target label --tune --tune-trials 50

Maximize your training speed and model efficiency with these built-in TrainIQ features.

Hardware Acceleration

TrainIQ automatically detects CUDA (NVIDIA), MPS (Apple Silicon), or CPU. To force a specific device, use:

config = trainiqConfig(device="cuda")

Mixed Precision (AMP)

Enable Automatic Mixed Precision to speed up training by 2-3x on compatible GPUs without losing significant accuracy.

config = trainiqConfig(mixed_precision=True)

Early Stopping

Prevent overfitting by automatically halting training when the validation loss stops improving.

config = trainiqConfig(early_stopping_patience=7)

Memory Management

Use pin_memory and adjust num_workers to optimize data transfers between CPU and GPU.

Generating an API scaffold is fully integrated. Just call .deploy() on your trained model. 

# Generate API scaffold
api_path = model.deploy(output_dir="my_api")

# To run your server:
# cd my_api
# pip install -r requirements.txt
# uvicorn app:app --reload

Command Line Interface
